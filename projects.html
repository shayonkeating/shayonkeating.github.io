Sardaukar May 2026

​
Rust
Bash/Shell
Homebrew

A lightweight Rust based CLI tool that silently compresses every prompt

Sardaukar is a rust based CLI tool that will silently compresses the input for every prompt before it hits your AI agent. It intercepts your prompt, strips unncessary softeners, strips articles, and truncates technical vocabulary.

A 30-50% reduction in input token usage!

Schnar Map February 2024

​
Python
D3.js
React.js
ETL

Schnar the gnar, find the pow, best ski conditions in the US exist here

SchnarMap is a web application that extracts transforms and loads current pow conditions into a user friendly website and dashboard that shows where in the United States currently have the best ski/snowboard conditions.

You can interact with the map and see where the best conditions exist from the last 72 hours. It is updated daily to reflect to ongoing change of conditions.

Links: Github schnarmap
